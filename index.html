01 · Mission Brief

Investigasi Financial Leakage pada Sistem Transaksi Fintech

Sebuah perusahaan fintech menemukan indikasi financial leakage. Revenue terlihat normal, namun tim Finance menemukan anomali yang memerlukan investigasi mendalam dari seorang Data Analyst.

"What happened to the company's money, and which transaction patterns should be investigated?"
Trigger Indicators
Jumlah refund meningkat signifikan
Beberapa transaksi bernilai sangat besar
Aktivitas transaksi pada waktu tidak biasa
Account menggunakan device berbeda dari biasanya
Transaksi dari lokasi yang tidak konsisten
Prinsip Analitik Project ini tidak bertujuan menyatakan seseorang sebagai pelaku fraud. Risk score digunakan untuk memprioritaskan investigasi — bukan sebagai bukti. Final determination tetap membutuhkan proses verifikasi lebih lanjut.
02 · Investigation Scope

Empat Domain Investigasi

Transaction
  • Total & distribusi nominal
  • Transaksi bernilai abnormal
  • Frekuensi & waktu transaksi
  • Pola per kategori
User Behavior
  • User dengan pola mencurigakan
  • Rata-rata transaksi per user
  • Aktivitas volume tinggi
  • Pola refund abnormal
Location & Device
  • Lokasi dengan aktivitas mencurigakan
  • Geographic inconsistency
  • Device digunakan banyak account
  • Transaksi dari device baru
Financial Impact
  • Total nilai transaksi berisiko
  • Estimasi potential loss
  • Nilai refund mencurigakan
  • Chargeback analysis

Recommendations
01
Data Understanding▾
Memahami struktur dataset sebelum analisis dimulai.
  • Jumlah baris, kolom, dan tipe data
  • Missing values & duplicate detection
  • Unique values & range nominal
  • Distribusi transaksi & periode waktu
  • Jumlah user, merchant, device

Output: Data profiling report
02
Data Cleaning & Validation▾
Memastikan data bersih dan valid sebelum analisis.
  • Handling missing values
  • Duplicate removal
  • Format timestamp correction
  • Amount validation (valid range, non-negative)
  • Standarisasi location, user ID, device ID, status

Output: Clean dataset siap analisis
03
Exploratory Data Analysis▾
Memahami baseline normal sebelum mencari anomali.
  • Transaction distribution & central tendency
  • Frequency by hour, day, location
  • Breakdown by payment method & category
  • Refund distribution analysis

"Anomali hanya bisa diidentifikasi setelah baseline normal dipahami."
04
Anomaly Investigation▾
Identifikasi tujuh indikator suspicious activity berdasarkan deviation dari baseline.
  • Unusual Amount, Unusual Location
  • Impossible Travel, New Device
  • Transaction Burst, Refund Abuse
  • Shared Device detection
05
Risk Scoring▾
Setiap indikator diberi bobot skor untuk memprioritaskan investigasi manual.
  • Impossible Travel: +40 pts (highest severity)
  • Unusual Location / Excessive Refund: +25 pts
  • Unusual Amount / Burst / Shared Device: +20 pts
  • New Device: +15 pts

Klasifikasi: LOW (0–30) · MEDIUM (31–60) · HIGH (61+)
06
Investigation Case & Recommendations▾
High-risk accounts dikelompokkan menjadi investigation case dengan timeline lengkap.
  • Case summary dengan risk score & flags
  • Transaction timeline per case
  • Related devices & locations
  • Financial impact estimation
  • Actionable business recommendations
