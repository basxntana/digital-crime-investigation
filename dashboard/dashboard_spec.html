DAX Measures

Semua calculated measures untuk dashboard. Dikelompokkan berdasarkan domain.

Transaction Metrics

Total Transactions
COUNTROWS(transactions)
Total Transaction Value
SUM(transactions[amount])
Average Transaction Value
AVERAGE(transactions[amount])
Median Transaction Value
MEDIAN(transactions[amount])

Risk & Suspicious Metrics

Suspicious Transactions
CALCULATE( COUNTROWS(transactions), transactions[refund_flag] = 1 || transactions[chargeback_flag] = 1 )
Suspicious Transaction Rate
DIVIDE( [Suspicious Transactions], [Total Transactions], 0 )
High Risk Users
CALCULATE( COUNTROWS(risk_scores), risk_scores[risk_level] = "HIGH" )
Composite Risk Score (User)
RELATED(risk_scores[composite_score])

Financial Impact

Refunded Amount
CALCULATE( SUM(transactions[amount]), transactions[refund_flag] = 1 )
Chargeback Amount
CALCULATE( SUM(transactions[amount]), transactions[chargeback_flag] = 1 )
Refund Rate
DIVIDE( CALCULATE(COUNTROWS(transactions), transactions[refund_flag] = 1), COUNTROWS(transactions), 0 )
Potential Loss Exposure
-- Refunded + chargeback on high-risk transactions (score >= 31) CALCULATE( SUM(transactions[amount]), FILTER( transactions, (transactions[refund_flag] = 1 || transactions[chargeback_flag] = 1) && RELATED(risk_scores[composite_score]) >= 31 ) )

Time Intelligence

Transactions MoM Growth
VAR CurrentMonth = [Total Transactions] VAR PriorMonth = CALCULATE( [Total Transactions], PREVIOUSMONTH(date_table[Date]) ) RETURN DIVIDE(CurrentMonth - PriorMonth, PriorMonth, 0)
Peak Transaction Hour
MAXX( TOPN(1, SUMMARIZE(transactions, transactions[txn_hour], "cnt", COUNTROWS(transactions)), [cnt], 1 ), transactions[txn_hour] )
